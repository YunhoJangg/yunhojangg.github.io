## 변수

* C언어와 마찬가지로, 변수 이름으로 예약어를 사용할 수 없다.
* `let` 과 `const`

  * `let`은 중복 선언이 불가하지만 값의 재할당이 가능함.
  * `const`는 상수 변수 선언 시 사용함.
* 변수명의 첫 글자는 숫자가 될 수 없다.

## 자료형

### String

* `" "`, `' '`, `` ` ` ``로 선언 가능하며, `' '`안에 또 `'`를 넣고 싶다면, `\'`와 같은 식으로 넣어주면 됨.
* string 내부에 변수를 넣을 때는 백틱(` `)을 사용해야함.
* string 안에 `${변수명}` 식으로 써주면 됨. (간단한 계산식도 가능)

### Number

* C언어처럼 `+` `-` `*` `/` `%` 계산이 가능함.
* 무한대 발산 시 `Infinity`, 문자를 숫자로 나누는 등의 계산은 `NaN (Not a Number)`가 뜸

### Boolean

* `true` `false` 형식

### null & undefined

* `null`은 값 x일시, `undefined`는 값 할당 x일 시

* 이외에도 객체형과 심볼형이 있음

### typeof

* 자료의 형식을 확인하는 명령어임.
* 다른 개발자가 작성한 데이터 타입이나, API 통신 등을 통해 받아온 데이터를 타입에 따라 다른 방식으로 처리해야 할 때 필요함.

### 출력 관련

* 출력할때 파이썬과 유사하게 `+`로 자료형끼리 더해서 하나의 문장으로 출력이 가능함.
* (ex. a에 `"장윤호"`, b에 `22`, c에 `"살"` 이 있다면 `a+b+c`는 장윤호 22살 이라는 문장이 됨)
