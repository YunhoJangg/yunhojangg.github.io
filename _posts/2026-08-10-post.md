1학년을 마치고 휴학을 한 뒤, 군대에 있으면서 나는 문득 앞으로 어떤 개발자가 되어야 할지 고민하게 되었다.
C언어 기초와 C언어로 자료구조를 배웠지만, 아직 백엔드, 시스템, AI 등 어떤 분야가 나에게 맞는지는 모른다.
그래서 당장 하나의 분야를 정하기보다는 **여러 분야를 경험하면서 기본기를 쌓는 것**을 목표로 하기로 했다.

## 내가 원하는 개발자
단순히 여러 기술을 조금씩 사용할 수 있는 개발자가 아니라,
**새로운 문제를 만났을 때 필요한 기술을 스스로 찾아 해결할 수 있는 개발자**가 되고 싶다.
이를 위해 한 분야만 깊게 파기보다는 여러 분야를 경험하고, 그 아래에 CS 기본기를 탄탄하게 쌓아가려고 한다.

---

## 1년 로드맵

### 1~2개월 — C
C를 다시 공부하면서 포인터, 메모리, 동적 할당, 파일 I/O 등을 제대로 이해한다.
간단한 자료구조 라이브러리를 직접 구현하며 C와 메모리에 익숙해진다.

### 3~4개월 — C++
C++의 객체지향과 STL을 공부한다.
간단한 CLI Todo 프로그램을 만들어보며 실제 프로그램을 구조화하는 경험을 한다.

### 5개월 — Linux
Linux 환경과 Shell, 프로세스, 파일 시스템 등을 익힌다.
가능하다면 C로 간단한 Shell을 직접 만들어본다.

### 6개월 — 자료구조 / 알고리즘
자료구조를 다시 정리하고 DFS, BFS, 정렬, 이분 탐색, DP 등의 기본 알고리즘을 공부한다.
문제를 많이 푸는 것보다 **왜 이 자료구조와 알고리즘을 선택했는지 설명할 수 있는 것**을 목표로 한다.

### 7개월 — 컴퓨터구조 / 운영체제
CPU, 메모리, 프로세스, 스레드, 가상 메모리, 동기화 등을 공부한다.
직접 간단한 멀티스레드 프로그램을 만들어보며 개념을 확인한다.

### 8개월 — 네트워크
TCP/IP, Socket, HTTP 등을 공부한다.
간단한 TCP 채팅 프로그램을 만들어 네트워크 통신을 직접 경험한다.

### 9개월 — Python
Python을 이용해 아이디어를 빠르게 구현하는 연습을 한다.
간단한 자동화 프로그램이나 API를 활용한 프로그램을 만들어본다.

### 10~11개월 — Web / Backend / Database
웹의 기본적인 구조를 이해하고 간단한 Backend 서버와 Database를 연결해본다.
최종적으로 작은 웹 서비스를 하나 만들어본다.

```text
Browser
   ↓
HTTP
   ↓
Backend
   ↓
Database
```

### 12개월 — 종합 프로젝트
1년 동안 배운 내용을 활용해 하나의 프로젝트를 완성한다.
이때부터 Docker 등의 개발 도구도 필요에 따라 경험해본다.

## 1년 후
1년 동안 여러 분야를 경험한 뒤 내가 어떤 문제를 해결하는 것을 가장 좋아하는지 돌아본다.

```text
C / C++
Linux
OS
Network
Backend
Database
Python
AI
Web
```

그 과정에서 자연스럽게 더 궁금해지는 분야가 생긴다면 그 분야를 다음 단계에서 깊게 공부한다.

---

## 목표
이 로드맵의 목표는 1년 안에 수많은 기술을 익히는 것이 아니다.
**여러 분야를 경험하고, 그 사이의 연결을 이해하며, 새로운 기술을 스스로 배울 수 있는 기반을 만드는 것**이다.
지금은 내가 어떤 개발자가 될지 정하지 않아도 된다고 생각한다.
일단 많이 경험해보고, 직접 만들어보고, 그 과정에서 내가 어떤 문제를 해결하는 것을 좋아하는지 찾아가려고 한다.
