원래는 순차적으로 C부터 하나하나 차근차근 골고루 공부하고 싶었는데, 어제 문득 뭔가 어플을 만들고 싶다는 생각이 들었다.
그래서 원래 계획대로 공부는 계속 진행하되, 이와는 별개로 앱 개발 공부를 해보고자 한다.

군대에서 앱 개발을 하려면 이전에 해달 해커톤 때 사용했던 Flutter로는 개발이 어렵다.
그래서 웹에서도 구동 가능한 React Native로 개발을 해야할 것 같은데, 나는 JavaScript도 사실 다뤄본 적이 없다는 것이다.
그렇기 때문에, 일단 JavaScript를 공부를 한 뒤에, TypeScript -> React -> React Native 순으로 공부해서
11월까지 간단한 어플을 하나 만들어보고 싶다.
